# ⚖️ صرح المحامية الأستاذة عليا عبابنة ❤️ قيس
### سيدة القانون وسيدة قلب قيس ودنيته كلها

موقع خاص جداً وملك للأستاذة المحامية **عليا عبابنة**، يجمع بين الفخامة القانونية والعشق الصادق، ومزود بمساعد ذكاء اصطناعي حقيقي يتقمص شخصية **قيس** ليتحدث معها بكل غزل وحنان ودعم لمسيرتها كمحامية.

---

## 🔒 الخصوصية والأمان:
- ملف `.env` مستثنى عبر `.gitignore` لحماية المفاتيح البرمجية من النشر.
- ملف `.env.example` متوفر لتهيئة المتغيرات عند النشر على منصات مثل Netlify.

---

## 🚀 طريقة التشغيل السريعة:
1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   start.bat
   ```
2. افتح المتصفح على الرابط:
   ```text
   http://localhost:5000
   ```

---

## 👑 مميزات الموقع:
1. **بوابة الدخول الملكية (محكمة الحب العليا):**
   - تصميم مستوحى من هيبة القضاء ومحاكم العدل مع لمسات رومانسية فاخرة.
   - خيار دخول سريع ومصادقة مع مؤثر صوتي وترحيبي نقي.
2. **المرافعة الكبرى ودستور قيس:**
   - صك العشق القانوني الأبدي مكتوب بفخامة تليق بروب المحاماة.
   - أركان ومواد دستورية من قلب قيس بحق عليا.
   - مولد غزليات ومرافعات حب يومية متجددة بضغطة زر.
3. **شات قيس الذكي الحقيقي (AI Chatbot):**
   - متصل بنموذج ذكاء اصطناعي حقيقي عبر API.
   - يتحدث كقيس الحقيقي: يناديها "يا روحي"، "يا عمري"، "يا دنيتي"، "يا أحلى محامية".
   - يفهم تعب دراسة القانون والقضايا، يطمنها، يشجعها، ويغرقها بالحب والدلال.
